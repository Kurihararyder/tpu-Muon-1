# RTL 設計說明（階段 C）

預設：8x8、資料 Q3.13（16 位元）、係數 Q4.12、累加器 32 位元（Q6.26）、五輪。選擇理由見 [format_study.md](format_study.md)。
RTL 只用 Verilog-2001 可合成語法（外加 `$clog2`），`rtl/` 內沒有工具專屬指令。

## 1. 模組階層

```
ns_top
├── norm_scale     X0 = G * scale（一級暫存）
├── ns_ctrl        FSM：下命令給核心
└── matmul_core    資料路徑：X／A／B 三個暫存器陣列 + 運算元選擇 + mac_unit + 捨入飽和
    └── mac_unit   兩級管線乘加單元
```

| 模組 | 檔案 | 功能 |
|---|---|---|
| `mac_unit` | rtl/mac_unit.v | 第 1 級鎖存運算元，第 2 級乘加；`clr` 以乘積取代累加器，`sh` 讓乘積左移 `SHL` 位（對齊係數與資料的小數點） |
| `norm_scale` | rtl/norm_scale.v | 把 Q4.12 的 G 乘以 Q4.16 的 scale，四捨五入、飽和成 Q3.13 |
| `matmul_core` | rtl/matmul_core.v | 逐元素執行 OP_A／OP_AAB／OP_X／OP_COMMIT |
| `ns_ctrl` | rtl/ns_ctrl.v | 五輪 × （A → AAB → X → COMMIT）的命令序列 |
| `ns_top` | rtl/ns_top.v | 頂層與載入／讀出介面 |

## 2. 參數

| 參數 | 預設 | 說明 |
|---|---|---|
| `N` | 8 | 矩陣大小（方陣；N 需 ≥ 2） |
| `W` | 16 | 資料位寬 |
| `F` | 13 | 資料小數位寬（Q3.13）。要改回 Q4.12 設 `F=12`；須 `F ≥ CF` |
| `CW`／`CF` | 16／12 | 係數位寬／小數位寬（Q4.12） |
| `ACCW` | 32 | 累加器位寬；小數位固定為 `2F`，整數位 `ACCW−2F` 須足以容納 ±2.74 以上（8x8 約需 3 位），實務上取 `2F+6` |
| `COEF_A/B/C` | 14109／−19558／8321 | round(係數 × 2^CF)。改 `CF` 時須同步更新（`python3 model/fixed_model.py` 可印出）。`ns_top` 也有同名參數並傳給 `matmul_core` |
| `GW`／`GF` | 16／12 | 輸入 G 的位寬／小數位寬（Q4.12），與資料位寬 `W` 獨立 |
| `SW`／`SF` | 20／16 | scale 位寬（無號）／小數位寬（Q4.16，範圍 0～16） |
| `STEPS` | 5 | Newton-Schulz 輪數 |
| `ARCH`（ns_top） | 0 | 0：序列式（`matmul_core`，單一 MAC，逐元素命令）；1：列平行（`matmul_core_par`，N 條 MAC，逐列命令） |
| `ROWMODE`（ns_ctrl） | 0 | 由 `ns_top` 依 `ARCH` 設定；1 時三個階段都只走列 |

## 3. 外部介面（`ns_top`）

為了避免 N·N·W = 1024 位元的寬匯流排佔用腳位，採記憶體式介面：

| 訊號 | 方向 | 說明 |
|---|---|---|
| `clk`, `rst_n` | in | 時脈、非同步低態重置 |
| `ld_we`, `ld_addr[5:0]`, `ld_data[GW-1:0]` | in | 載入一個元素，位址 = i·N + j，資料為 G（Q4.12，二補數） |
| `scale[19:0]` | in | 1 / (‖G‖F + eps)（Q4.16）；載入期間須保持穩定 |
| `start` | in | 載入完成後拉高一個週期（可與最後一筆載入同週期） |
| `busy`, `done` | out | `done` 為準位訊號：start 後立即清為 0，完成後拉高並保持 |
| `rd_addr[5:0]`, `rd_data[W-1:0]` | in/out | 非同步讀出結果（Q3.13，二補數） |

`ld_data`、`rd_data` 在頂層不宣告 `signed`：Yosys 會把 `signed` 寫進網表的埠宣告，OpenSTA 讀不進去（ORFS 流程會失敗）。內部模組仍是有號運算。

使用順序：設定 `scale` → 64 個週期載入 G → `start` → 等 `done` → 讀 64 個輸出。

## 4. 資料路徑與命令

三個暫存器陣列（每個 64×16 位元）：

| 陣列 | 內容 |
|---|---|
| X | 目前的 X；載入埠寫入；COMMIT 時整個被 A 陣列覆蓋 |
| A | `OP_A` 寫入 A；`OP_X` 之後兼作新 X 的緩衝（避免原地覆寫還要用到的 X） |
| B | `OP_AAB` 寫入 B |

| 命令 | 運算 | 週期數 |
|---|---|---|
| `OP_A (i,j)` | A[i][j] = Q(Σₖ X[i][k]·X[j][k])，同時寫 A[j][i] | 11 |
| `OP_AAB (i,j)` | AA = Q(Σₖ A[i][k]·A[j][k])，B[i][j] = Q(b·A[i][j] + c·AA)，同時寫 B[j][i] | 15 |
| `OP_X (i,j)` | X′[i][j] = Q(Σₖ B[i][k]·X[k][j] + a·X[i][j])，寫入 A 陣列 | 12 |
| `OP_COMMIT` | X ← A 陣列（一個週期、平行複製） | 1 |

- Q(·) = 加 0.5 LSB、算術右移 13 位、飽和到 16 位元。
- A 與 A·A 皆為對稱矩陣，所以只算上三角（含對角）並鏡射寫入：36 個元素而不是 64 個。鏡射位置的值與直接計算逐位元相同（乘積相同、加總順序相同）。
- A·A 用「列內積」`Σₖ A[i][k]·A[j][k]` 計算，因為 A 對稱，A[k][j] = A[j][k]，所以兩個運算元都是按列讀。
- B 的計算併在 `OP_AAB` 內，用同一個 MAC 做兩次係數乘法，不另設乘法器。
- 係數乘積是 Q4.12 × Q3.13 = 小數 25 位，左移 1 位對齊到累加器的 26 位。
- 一輪的週期數：36×11 + 36×15 + 64×12 + 1 = 1705；五輪約 **8,525 個週期**（估算值，階段 D 以模擬實測確認）。

## 5. 驗證狀態

與 Python 位元精確模型 [model/fixed_model.py](../model/fixed_model.py) 的對應：`norm_scale` → `norm_scale()`；`matmul_core` + `ns_ctrl` → `ns_int()`。

- `model/check_fixed_model.py`：整數模型與浮點實作的定點模型（階段 B 的 `ns_fix`）200/200 組位元一致；整條路徑（含輸入量化與 scale 量化）對 float64 的誤差，20 組隨機 8x8 為最大 5.91e-03、平均 4.57e-04，與階段 B 的純 Q3.13 評估（6.10e-03／4.61e-04）相當。
- `sim/run_unit.sh`：四個模組各自的 testbench 與 Verilator lint 全部通過。
  - `tb_mac_unit`：500 組隨機長度序列，含極值與保持檢查。
  - `tb_norm_scale`：5000 筆隨機與邊界輸入，含飽和與無效週期。
  - `tb_ns_ctrl`：以隨機忙碌延遲的假核心，檢查 685 個命令的順序，連跑兩次。
  - `tb_matmul_core`：逐階段（A、B、X′、COMMIT）與 TB 內的整數參考比對，含小幅值與大幅值（觸發飽和）兩輪。
- 變異測試：故意改壞 RTL（係數差 1 LSB、少加捨入常數、拿掉鏡射寫入、移位錯誤、累加改成相減、少算對角、不飽和），各 testbench 都能抓到。

- 頂層整體模擬（`sim/run.sh`，階段 D）：20 組測試向量、1280 個輸出元素與位元精確模型逐位元一致；另以 `--variant w12|w24` 驗證 12／24 位元變體。詳見 [sim_report.md](sim_report.md)。
- 合成與佈局繞線（階段 E）：ORFS 完整流程通過，DRC／天線違規皆為 0，詳見 [ppa_table.md](ppa_table.md)。

## 6. 已知限制與後續

- 只支援方陣（`rows > cols` 時的轉置未實作）。
- scale 由外部算好；範圍 0～16，若 ‖G‖ 太小（< 1/16 × 最大元素）會飽和。平方和與開根號留待後續。
- 累加器溢位時環繞、不飽和；8x8 的實測最大值 2.74，Q6.26 有充足餘裕。矩陣放大或輸入分布不同時須重新檢查。
- 暫存器陣列用 3 × 1024 個正反器（約 3.1k），合成後面積多半由它主導；之後可評估縮減（例如 B 與 A 共用、對稱矩陣只存一半）。
- 讀出埠為非同步組合讀取，會形成 `rd_addr → rd_data` 的 I/O 組合路徑（見 ppa_table.md 3.2）。
- 單一 MAC，無運算重疊（命令之間、讀取與乘加之間皆未管線化重疊），屬「先求正確」版本。

## 7. 列平行架構（`ARCH=1`）

`matmul_core_par` 與 `matmul_core` 介面相同（`cmd_j` 不使用），命令改為逐列：每個命令由 N 條 MAC lane 同時算出列 i 的 N 個元素。每個命令的週期數與序列版的單一元素相同（OP_A 11、OP_AAB 15、OP_X 12），一輪 = 8×(11+15+12)+1 = 305，五輪 **1,527 個週期**（序列式 8,527；模擬實測）。不使用 A 的對稱鏡射，所以 A 與 A·A 要算整列。數值運算與序列版一模一樣，輸出逐位元一致。驗證：`tb_matmul_core_par`（逐階段與整數參考比對，變異測試能抓到 lane 位址錯誤、B 寫入列號錯誤、`aa_q` 未鎖存、係數差 1 LSB）、`tb_ns_ctrl`（`ROWMODE=1`，125 個命令）、`sim/run.sh --arch par`（20 組向量，含 12／24 位元）。PPA 比較見 [ppa_table.md](ppa_table.md) 3.5。
